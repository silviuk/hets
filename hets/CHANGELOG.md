# Changelog

## 1.0.0
- Initial release of HETS Home Assistant App.
- Standardized to latest Home Assistant App schema (`apptype: app`, `stage: stable`).
- Support for multi-source scraping (GitHub Markdown docs and official endpoints).
- Direct EVCC REST API hot-reload support.
- Native Home Assistant persistent notifications.
- Multi-architecture container support (`aarch64`, `amd64`, `armhf`, `armv7`, `i386`).
